2. Web Server Boundary
apps/web • Next.js
Mandatory Multi-Tenant Guard (ADR-001)

Every request extracts auth.uid() from Supabase session. Server-side lookup confirms StudioUser membership. Sets transaction-scoped app.studio_id. Never trusts browser tenant ID.

Server Actions & Route Handlers
Server-only modules owning studio business workflows & authorization:
  • Member Operations: Lifecycle (Active, Paused, Expired, Cancelled)
  • Attendance Engine: Same-day check-in idempotency (1 visit per member/day)
  • CSV Ingestor: Member resolution & batch validation
  • Dashboard Aggregator: Rolling 7d & 30d KPI calculators
Intelligence Service Gateway
Explicit internal HTTP client passing authorized studio member arrays to the Python intelligence service.
↓ Prisma Client • Transaction-Scoped app.studio_id
3. Data Platform Tier
Supabase PostgreSQL
Prisma ORM (packages/database) Schema Authority
Prisma Migrate is the sole schema authority. Emits declarative migrations with custom SQL for RLS policies.
PostgreSQL Row Level Security (RLS)
Defense-in-depth isolation across all tenant tables:
  • Studio & StudioUser: Tenancy membership
  • Member: Profile & contact scoping
  • MembershipPeriod: Lifecycle timeline records
  • AttendanceRecord: Unique on (member_id, local_date)
  • RetentionAssessmentSnapshot: Immutable score audit
  • OutreachInteractionLog: Owner intervention history
Synthetic Data Seeder
Controlled seed loader in tools/synthetic-data populating deterministic test scenarios without bypassing RLS.

4. Intelligence Tier
services/intelligence
Python 3.12+ & FastAPI Microservice
Isolated analytics and machine learning service. Strictly decoupled from direct browser access.
Deterministic Retention Engine
ADR-002: Transparent, explainable risk scoring:
  • Recency (25%): Inactivity days (0, 30, 65, 100)
  • Trend (35%): 30d vs 30d drop percentage
  • Expiry (25%): Days to effective expiration
  • Renewal (15%): Historical non-renewal rate
  • Dynamic Weight Redistribution: Re-weights available dimensions proportionally if history < 2 cycles.
Gemini AI Narrative Copilot Google ADK
Generates human-readable, grounded retention recommendations strictly constrained to structured dimension facts. Zero hallucination.
→ Structured JSON Risk Payload to Web Server
