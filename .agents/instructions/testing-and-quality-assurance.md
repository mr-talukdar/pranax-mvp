# Testing and Quality Assurance

Use this instruction to plan and verify a task.

1. Identify observable behavior and boundary risks before choosing tests.
2. Run the smallest relevant test or check first.
3. Add focused tests for behavior introduced or changed by the task.
4. Escalate to integration or end-to-end checks for service, contract, tenancy, or authorization risks.
5. Record commands executed and results.
6. Do not claim a check passes when it was not run or did not complete.

At minimum, consider type checking, linting, unit tests, integration tests, and formatting for affected languages. Skip only with a documented reason.
